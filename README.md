# 🛳️ Prediksi Keselamatan Penumpang Titanic dengan Decision Tree

Proyek ini menggunakan algoritma **Decision Tree Classifier** untuk memprediksi apakah penumpang Titanic selamat atau tidak berdasarkan data seperti jenis kelamin, usia, kelas tiket, jumlah keluarga, dan pelabuhan keberangkatan.

## 📂 File
- `DecisionTree_Titanic.ipynb` — Notebook Jupyter yang berisi seluruh proses eksperimen machine learning.
- `decision_tree_titanic.png` — Visualisasi pohon keputusan dari model yang dilatih.

## 📊 Dataset
Dataset yang digunakan adalah `titanic.csv`).

Fitur yang digunakan:
- `Pclass`, `Sex`, `Age`, `SibSp`, `Parch`, `Fare`, `Embarked`

Target:
- `Survived`

## 🔍 Langkah-Langkah Eksperimen
1. Pembersihan Data
2. Split Data
3. Pelatihan Model
4. Evaluasi
5. Visualisasi

## 🧰 Library
- `pandas`, `scikit-learn`, `matplotlib`

1. Buka `DecisionTree_Titanic.ipynb` di Jupyter/Colab
2. Jalankan seluruh sel
